# 課程講義與圖示管理

1. 從網站的「網站管理」進入 Pages CMS，使用原本的 GitHub 帳號登入。
2. 開啟 `JimHaoCh / JimHaoCh.github.io` 的 `main` 分支，選擇「課程講義」。
3. 新增課程，填寫中文與英文名稱、課號、學年度、學期及簡介。
4. 在「講義與學習資源」新增單元，填寫週次、單元名稱與更新日期。
5. 使用「上傳講義」選擇 PDF、PPTX、PPT、DOCX 或 ZIP。檔案存放在 `assets/handouts`。若使用外部資源，填寫 `https://` 網址。
6. 同時填入檔案與外部連結時，前台優先使用上傳檔案。
7. 開啟「在網站顯示」並儲存。等待 GitHub Pages 發布完成後，到課程頁確認連結。

網站會依你在後台的排列顯示課程與單元。不同學期的同一門課可建立獨立紀錄，保留歷年教材。刪除列表項目不會自動刪除已上傳檔案。

## 教材公開範圍

目前儲存庫與網站公開。上傳的教材可經由網址存取；顯示開關只影響課程列表。限制修課學生使用的教材，請放在校務平台或有存取權限的雲端資料夾，網站提供入口連結。

## 圖示

最新消息、實驗儀器、生活剪影與技術簡介都有「裝飾圖示」選單。選擇與內容相關的圖示即可，未選擇時會使用該頁預設值。文字標題會保留，圖示作為裝飾。

## 行事曆

行事曆目前為預留頁，尚未連接 Google，也未讀取任何私人行程。準備公開時，可提供指定行事曆的公開網址或內嵌程式碼再接入。
