ImageJ.JS 影像分析教學入口

Image Analysis · Microscopy · Quantitative Imaging

以醫技系鏡檢與基礎影像分析教學為目的，提供學生前往 ImJoy 團隊開發的 ImageJ.JS 網頁版，練習影像校正、感興趣區域（ROI）選取、強度量測與粒子計數。

使用前請留意

本頁為校內教學導引頁。ImageJ.JS 由第三方 ImJoy 團隊開發及提供服務，點擊下方連結後會離開本實驗室網站。本網站沒有託管、修改、複製或嵌入 ImageJ.JS、CheerpJ 及其插件，也沒有取得或傳送您的影像檔案。外部網站的資料處理方式、服務狀態與授權條件依其營運方規定。

GETTING STARTED

課堂操作流程

以下是適合第一次使用 ImageJ 的基本練習；實際選單名稱及功能依外部網站版本而定。

  1. 01

    開啟網頁版

    點選上方按鈕，在新分頁啟動 ImJoy 團隊提供的 ImageJ.JS。

  2. 02

    讀入練習影像

    選擇 File → Open 或網站提供的 Select Local File，優先使用教師提供的合成、公開授權或已去識別化範例影像。

  3. 03

    設定比例與 ROI

    若影像包含已知尺寸的比例尺，可使用 Analyze → Set Scale 校正；再用矩形、橢圓或自由選取工具建立 ROI。

  4. 04

    量測與紀錄

    依練習題目選擇 Analyze → Measure，或進行 Threshold、Analyze Particles。記錄操作參數、校正值與人工核對結果。

CLASSROOM EXERCISES

建議教學練習

01 · MORPHOMETRY

細胞大小與形態量測

依比例尺設定空間校正，框選單顆細胞 ROI，量測面積、周長與長軸尺寸。

核心概念：Pixel-to-µm calibration · ROI

02 · PARTICLE ANALYSIS

細胞／顆粒計數

練習 Image → Adjust → Threshold 與 Analyze → Analyze Particles，觀察閾值對計數和黏連顆粒的影響。

核心概念：Segmentation · Size filtering

03 · IMAGE INTENSITY

染色與影像強度

對背景及目標 ROI 進行平均灰階值量測，討論曝光、背景扣除與飽和訊號的影響。

核心概念：Mean gray value · Background
