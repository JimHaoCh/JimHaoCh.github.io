MEDTECH VIRTUAL LAB · IMAGE ANALYSIS v0.2

Web-Image Lab 鏡檢影像分析教學

Image Analysis · Microscopy · Quantitative Imaging

第二版新增本站原創的純瀏覽器影像分析工作台，可直接在網站內操作 ROI、灰階量測、閾值分割、粒子計數與檔案匯出；需要進階 ImageJ 功能時，可另外前往 ImJoy 團隊開發的 ImageJ.JS 網頁版。

使用前請留意

本站自製 Web-Image Lab 採原生 JavaScript Canvas，影像在您的瀏覽器中處理，程式未加入影像上傳接口或第三方分析函式庫。完整 ImageJ.JS 由第三方 ImJoy 團隊提供；本網站沒有託管、修改、複製或嵌入 ImageJ.JS、CheerpJ 及其插件。點擊外部連結後會離開本站，資料處理方式依外部服務政策。

開啟本站影像分析工作台 →\n 前往完整 ImageJ.JS ↗ 查看 ImageJ 專案介紹 ↗

本站工作台為教學用簡易分析原型，支援桌面與觸控操作；ImageJ Macro 與 TIFF Stack 等完整功能需另前往外部 ImageJ.JS，請先閱讀資料保護提醒。

GETTING STARTED

課堂操作流程

可先在本站工作台完成基本練習；以下提及的 ImageJ 選單名稱，則對應外部完整版 ImageJ.JS。

  1. 01

    開啟網頁版

    點選上方「本站影像分析工作台」進行本機練習；進階功能可另開第三方 ImageJ.JS。

  2. 02

    讀入練習影像

    於本站使用「合成細胞示範」或上傳 PNG／JPEG／WebP；外部 ImageJ.JS 可以使用 File → Open。

  3. 03

    設定比例與 ROI

    在本站輸入經確認的 µm/pixel，再拖曳矩形 ROI 或直線；外部 ImageJ 可使用 Analyze → Set Scale。

  4. 04

    量測與紀錄

    在本站調整 Threshold 後執行連通區計數，再匯出 CSV／PNG；外部 ImageJ 可使用 Analyze → Measure 或 Analyze Particles。

CLASSROOM EXERCISES

建議教學練習

01 · MORPHOMETRY

細胞大小與形態量測

依比例尺設定空間校正，框選單顆細胞 ROI，量測面積、周長與長軸尺寸。

核心概念：Pixel-to-µm calibration · ROI

02 · PARTICLE ANALYSIS

細胞／顆粒計數

練習 Image → Adjust → Threshold 與 Analyze → Analyze Particles，觀察閾值對計數和黏連顆粒的影響。

核心概念：Segmentation · Size filtering

03 · IMAGE INTENSITY

染色與影像強度

對背景及目標 ROI 進行平均灰階值量測，討論曝光、背景扣除與飽和訊號的影響。

核心概念：Mean gray value · Background

資料保護與判讀界線

  • 僅使用教師提供的範例、合成影像或確認可公開使用的素材。
  • 請勿在第三方網頁上傳可識別病人身分的臨床檢體影像、病歷資訊或其他機敏資料。
  • 外部服務與插件可能有各自的資料傳輸流程；使用前應確認其政策與功能。本站無法保證外部處理完全限於本機。
  • 練習結果須人工檢查；本教學入口及外部軟體均未由本站驗證為臨床檢驗或診斷系統。
