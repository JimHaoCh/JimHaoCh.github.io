# 百洑傳息｜Bioflumen & Xensor Lab

Website for Chun-Hao Chang, Assistant Professor, Department of Biotechnology and Laboratory Science in Medicine, National Yang Ming Chiao Tung University.

## GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, **main**, **/(root)**, then Save. The site uses static HTML, CSS and JavaScript; no build tools or API keys are needed.

## Files

- `index.html`: laboratory, research, PI, selected publications and contact information.
- `style.css`: layout and responsive styles.
- `site.js`: mobile navigation and publication filters.
- `chun-hao-chang.jpg`: PI portrait from the departmental profile.
- `.nojekyll`: serve the static site directly.

Content source: https://dmt.nycu.edu.tw/en/張鈞豪老師/

Profile retrieved 2026-10-08. Selected publications are the PI’s historical work.
