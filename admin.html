登入 Pages CMS Open editor ↗

首次使用

  1. 登入 GitHub。
  2. 安裝 Pages CMS GitHub App，選擇 Only select repositories，勾選 JimHaoCh.github.io。
  3. 回到 Pages CMS 開啟此 repository；編輯欄位已設定完成。

日常更新

在側欄選擇課程講義、最新消息、儀器、生活剪影、技術簡介、成員、著作或首頁文字。新增項目、填寫中英文、上傳照片，再按 Save。

「在網站顯示」控制該項目是否出現在網站。儲存後，等待 GitHub Pages 自動發布完成，再重新整理網站。

消息與生活剪影依日期由新至舊排列；儀器、技術與成員依您在編輯器中的排列顯示。

課程講義

  1. 選擇「課程講義」，新增課程名稱、學年度與學期。
  2. 在「講義與學習資源」新增各週單元，填寫名稱與更新日期。
  3. 上傳 PDF、PPTX、PPT、DOCX 或 ZIP；也可填寫 https:// 外部資源連結。
  4. 儲存後等待網站發布完成，再確認課程頁的檔案連結。

教材檔案上傳至公開 GitHub 儲存庫。僅限學生的教材請使用具存取權限的雲端或校務平台連結。「在網站顯示」只控制列表顯示。
